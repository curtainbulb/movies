GitHub repo sync

Loads a .md file from a GitHub repo automatically on open, and writes every change back to it, so this collection stays identical across every device that opens this page. Uses the GitHub Contents API, which needs a repo-scoped token — not the Gist token, if you also use the separate Gist backup below.

GitHub Gist sync

Stores this collection in a private GitHub Gist and keeps it in sync across every device that opens this page with the same token. Lighter to set up than the repo sync above: no repo to create first, and the token only needs the narrower gist scope. Running both at once is fine — they sync independent copies.

Studio






Suggestions come from the model you set up under AI models. Every title is checked against Wikipedia; unmatched titles are flagged and start unselected, and the written reasons are generated, not retrieved. Titles, years, categories, and your highest ratings are sent. Notes are never sent.






Show exactly what will be sent












These tools run on your own collection. Lookups send only a film title and year to Wikipedia, Wikidata, or TMDB.


Shape of the collection


Possible duplicates
Matches alternate titles, leading articles, accents, and years one apart. Merging combines ratings, notes, and history, and can be undone.


Fill in missing details
Finds runtime, director, languages, and countries for films that lack them. Only matches that agree on title and year are proposed, and existing values are never overwritten.


Artwork
Clears stored misses and failures so missing posters are searched again with every available source.






Connect a Markdown or text list hosted online. New films are added automatically and can be undone. Your ratings, notes, and watch history on films you already have are never overwritten, and films dropped from the source are only removed when you confirm. GitHub, Gist, Dropbox, Google Drive and Docs, OneDrive, SharePoint, pCloud, Pastebin, and common raw text links are recognized. Do not use addresses that contain secret tokens.
